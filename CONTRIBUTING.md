# Contributing to Awesome AI Agent Skills

Thank you for your interest in contributing! 🎉

## 🌟 Ways to Contribute

### 1. Add a New Skill
Got a useful AI prompt or workflow? Share it as a skill!

- Fork the repository
- Create a new folder under the appropriate pack (`development-skills/skills/`, `srs-skills/skills/`, or `virtual-team-skill/skills/`)
- Add a `SKILL.md` file with:
  - Clear description of what the skill does
  - Usage instructions
  - Example output (if applicable)
- Submit a Pull Request

### 2. Improve Existing Skills
- Fix typos or unclear instructions
- Add better examples
- Improve compatibility with more AI agents

### 3. Report Issues
Found a skill that doesn't work as expected? [Open an issue](https://github.com/huuanh20/awesome-ai-agent-skills/issues)

### 4. Share & Spread the Word
- ⭐ Star this repo
- Share on Twitter/X, Reddit, or your blog
- Tell your developer friends!

## 📋 Skill Template

```markdown
# Skill Name

## Description
What this skill does in 1-2 sentences.

## Best For
- Use case 1
- Use case 2

## Usage
\`\`\`
/your-command "description of what you want"
\`\`\`

## Example Output
What the AI agent will produce.

## Compatible With
- ✅ Claude Code
- ✅ Cursor
- ✅ Gemini CLI
- ✅ GitHub Copilot
```
