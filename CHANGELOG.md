## [1.0.0] - 2025-07-24

### 🎉 Initial Release

#### Added
- **40 AI skill packs** organized into 3 major bundles
- **Development Skills** — full development lifecycle toolkit
  - `/plan` — implementation planning
  - `/cook` — code generation
  - `/fix` — debugging & root cause analysis
  - `/test` — test generation (unit, integration, e2e)
  - `/quality` — code quality review
  - `/review` — full code review with severity ratings
- **SRS Skills** — IEEE 830-1998 SRS generation pipeline
  - `/cl:srs` — quick SRS from existing requirements
  - `/cl:srs-flow` — full 7-step pipeline with validation
- **Virtual Team Skill** — 7-role AI team simulation
  - BA → TechLead → PM → BE Dev → FE Dev → Tester → QA/QC
  - `--level` flag: `fresh` · `junior` · `mid` · `senior`
- **Multi-agent support**: Claude Code, Cursor, Gemini CLI, Codex, GitHub Copilot
- **Multi-language README** with Google Translate links (10+ languages)
- MIT License
- Contributing guide & Code of Conduct
- GitHub Issue & PR templates
